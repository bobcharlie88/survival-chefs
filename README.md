# Survival Chefs (WildChef Survival)

An **offline-first survival app** that combines gourmet wild-food recipes, foraging,
fishing, bushcraft, first aid, navigation and survival knowledge.

> Independent project. Not part of WildEx and shares no code with it.

## Who it's for
Campers · Hunters · Foragers · 4WD travellers · Boaties · Hikers · Survivalists

## Platforms
Android · iPhone · Web

## Data
- SQLite on-device (fully usable offline)
- Cloud sync when a connection is available

## Planned features
- Species identification (edible / dangerous plants, fish, game)
- Wild-food recipes
- AI Chef (turn what you found into a meal)
- AI Survival Assistant
- Offline maps & navigation
- First aid
- Bushcraft
- Water purification
- Fishing guide
